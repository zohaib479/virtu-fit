# Clothing Simulator

Clothing Simulator creates AI-powered virtual try-on images from a person photo and a garment photo. It includes sample images, a comparison slider, and a local history gallery.

## Run Locally

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

To generate a production build, run `npm run build`.

## OpenAI API Key

Add an OpenAI API key in the app to generate images with OpenAI. The key is stored in your browser's local storage and sent directly to OpenAI. Demo mode is available without a key.
